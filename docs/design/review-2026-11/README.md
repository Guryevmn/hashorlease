# Дизайн-ревью HashOrLease — ноябрь 2026

Цель: довести интерфейс до записи ролика (24–27.11, дизайн готов до 23.11).
Как снято: приложение в демо-режиме (выдуманные данные, без кошелька и живого агента), Chrome, ширины 1440 и 390 px (телефон — в двойной плотности).

Папки:
- `before/` — все 6 экранов «как сейчас», целиком, на 1440 и 390 px (12 картинок).
- `after/` — те же экраны с правками из мокапа, первый экран (12 картинок).
- `pairs/` — 9 пар «было / станет» по главным правкам.

Мокап — это настоящий код в ветке `agent/design-review` (CSS и мелкие правки разметки, логику не трогал). Его можно влить целиком или по пунктам.

Приоритеты: 🎬 для ролика · ➕ желательно · ⏳ потом. Время — работа исполнителя вместе с проверкой.

## Топ-5 для ролика

1. **Телефон: страница шире экрана** — пара `02`. Сейчас ширина страницы 444 px при экране 390: плашка расхода вылезает за край, сайт ездит вбок. ~15 мин.
2. **Шапка в одну строку, одна плашка, спокойная полоса демо** — пара `01`. ~30 мин.
3. **Убрать служебную строку «Preview states (mock)» внизу** — пара `03`. ~10 мин.
4. **Карточка площадки: понятное сравнение трёх вариантов** — пара `04`. ~20 мин.
5. **Лимит, заданный на сервере, не выглядит редактируемым** — пара `05`. ~20 мин.

Вместе ~1,5 часа. В ветке все пять уже сделаны: остаётся выбрать и влить.
