# Зелёная галочка «Verified» и иконки в кружках по центру

Лист «Was | Now» (402 и 1280 px): `sources-402.png`, `sources-1280.png` (карточка «Where the numbers come from»),
`receipt-402.png`, `receipt-1280.png` (шторка чека). Исходные снимки — `raw/` (`before-*` / `after-*`).

- **По центру.** Кружок-иконка (`.chip-wrap`) стоял по середине строчных букв, а не заглавных: был на 3,6 px ниже.
  Теперь центр кружка = середина заглавных строки (измерено в браузере: 0,01 px на 19 px шрифте, 0,03 px на 15 px).
  Один класс — чинит все места: источники чисел, строка «Mining income» на главной, форма «market guide».
  Сам знак внутри кружка (галочка, глобус, человечек) уже стоял по центру; галочка сдвинута на 0,25 px вверх по сетке.
- **Зелёный.** `Verified` (галочка Telegraph) — `--mine #1e7a46` на `--mine-bg #e4f4ea`: контраст 4,7:1 (нужно ≥ 3:1).
  В шторке чека статус «Verified» — тот же зелёный. Фиолетовый — только кнопки, ссылки, переключатели, чип «Lease to AI».

Как пересобрать: см. `design/receipt-redesign/README.md` (копия приложения без ключа кошелька),
затем `node _source/shot.mjs http://localhost:3471 raw before|after` (+ `measure` — числа смещения),
`uv run --with pillow python3 _source/compare.py`.
