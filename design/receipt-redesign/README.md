# Шторка чека и пауза в History — редизайн в приложении (на выбор)

Ветка `agent/receipt-redesign`, не влита в main (сайт обновляется из main сам — вливаем после «ок» Михаила).
Снимки сделаны с локальной копии приложения без ключа кошелька: ничего не покупалось. Цена BTC в снимках — из последнего
чека копии ($64,155), в ролике будет та, что на экране в день съёмки.

## Картинки «было / стало»

- `receipt-402.png`, `receipt-1280.png` — шторка чека: было, вариант А, вариант Б.
- `pause-402.png`, `pause-1280.png` — History, пауза 17.11: было, вариант А, вариант Б.
- `chips-402.png`, `chips-1280.png` — один фиолетовый для чипсов и переключателей: было, стало.
- `raw/` — исходные снимки (`before-*` — main, `a-*` — вариант А, `b-*` — вариант Б).

## Что изменилось

**Шторка чека.** Сверху статус («Verified · by a Telegraph receipt», фиолетовая галочка), ниже крупно что куплено
(«BTC price $64,155») и сколько стоило («Paid $0.010 USDC · testnet»), затем кнопка «View Telegraph receipt ↗».
Технические поля (сервис, провайдер, время, хеш с кнопкой Copy, сеть) — вторым уровнем, сгруппированным списком.
На телефоне — шторка с «ручкой», чистое затемнение с лёгким размытием вместо полупрозрачного текста позади,
без мутной тени; на компьютере — поповер с тонкой обводкой и короткой лёгкой тенью.
- Вариант А (рекомендую): крупная цена, заполненная фиолетовая кнопка, детали видны сразу.
- Вариант Б: две плитки (цена и оплата), светлая кнопка, детали свёрнуты под «Technical details».

**Пауза.** Чип «Paused», причина обычным цветом, места полностью; над паузой строка «↑ Back to decisions from 20:00».
- Вариант А (рекомендую): 13 часов × 3 места = 39 серых строк сворачиваются в один блок «Paused 07:00–19:00 UTC · 13 h»;
  по нажатию раскрываются часы.
- Вариант Б: строка на каждый час, но с чипом «Paused» и названием места как у обычной строки.

**Название места на телефоне.** В режиме «All places» тег «Agent call» на телефоне переехал в раскрытую строку —
названия («Silesia Farm», «Leipzig Hub») больше не обрезаются.

**Один фиолетовый.** Чип «Lease to AI», логотип, ссылки, «Changes only», выбранный период (24 h / 7 d / 30 d) и кнопки
отметок (Followed / Other / Skip) — один цвет `#5b3fd1` с одной светлой парой `#efebfc` (раньше период и отметки были
чёрными, у чипа был свой оттенок фона). Галочка чека Telegraph тоже фиолетовая (зелёный остаётся только у «Mine»).
Тёмной темы в приложении нет; `#948dff` — тот же цвет для тёмного фона (иконка, ролик).

## Как посмотреть вариант Б в приложении

Добавить к адресу `?receipt=b` (шторка) или `?pause=b` (пауза). После выбора лишний вариант удалю из кода.

## Как пересобрать

1. Копия данных: `rsync -a --exclude 'shots*' ../../data ./` (папка `data/` не в git).
2. `NEXT_PUBLIC_DATA_MODE=live npx next dev -p 3471` (без ключа кошелька; открывать через `localhost`, не `127.0.0.1`).
3. `node design/receipt-redesign/_source/shot.mjs http://localhost:3471 design/receipt-redesign/raw a`
   и `Q="?receipt=b&pause=b" node … b receipt-402 receipt-1280 pause-402 pause-1280`.
4. `uv run --with pillow python3 design/receipt-redesign/_source/compare.py`.
